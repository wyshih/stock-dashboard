# 台股預測系統 — 公開展示站

> ⚠️ **本站顯示的是模型測試期（2025-02 ~ 2026-07）的回溯結果，不是即時預測，
> 不構成任何投資建議。** 歷史績效不代表未來表現。

一個台股「未來 20 個交易日會不會漲過半數天數」預測模型的成績單。
10 個 RandomForest 模型（5 種特徵集 × 2 種 ground truth 定義），
全部用 Round 4 切分：訓練 2020-01~2023-11、驗證 2024、測試 2025-02~2026-07，
兩個交界各留一個月 embargo。

## 四頁

1. **推薦名單** — 測試期任一天、各模型的分數，門檻滑桿旁顯示驗證期曲線上的
   訊號數 / 勝率 / 平均報酬
2. **個股技術面** — 1,990 檔可查；148 條技術說法各自掛著全市場全歷史的條件統計
   （樣本數、勝率、與隨機進場的差距）；圖表指標由行情現算
3. **模型成效／回測** — 絕對門檻版 + **訊號數對齊版**兩張表，加上驗證期門檻曲線
4. **關於** — 方法論、切分、生存偏差等限制、免責聲明

## 為什麼一定要看「訊號數對齊版」

這個系統「訊號越少報酬越高」。用固定門檻比較不同模型，比的其實是**門檻鬆緊**，
不是模型好壞 —— 門檻嚴的模型自然看起來報酬高。訊號數對齊版讓每個模型每天都只
發相同比例（前 1.5%）的訊號，那才是同一條起跑線。

## 跑起來

```bash
make install   # 建 venv 裝套件（不需要 TA-Lib）
make app       # http://localhost:8501
```

`public_data/` 的資料包由 private 的 engine repo 用 `make export-public` 產生，
這個 repo 不自己算任何東西 —— 不推論、不建特徵、不判定技術型態。

## 誠實聲明

- **生存偏差**：資料來自官方端點的現存清單，已下市的股票不在裡面。
  「歷史上出現這個型態後平均漲 X%」天生偏樂觀。
- **不是即時預測**：模型沒有在這個站上跑推論，每個數字都是回溯出來的。
- **測試期不代表未來**：門檻是在 2024 下半年的驗證期上由人挑的；
  測試期沒有參與挑選，但它終究只是一段特定的市場環境。
